# 이전 키컬러 비교 시안

2026.09.11 공식 키컬러를 UNIT TX Blue `#0064FF`로 확정했다.

이 폴더의 20색·40개 JSON은 색상 선택 과정의 보관 자료다. 다른 색상은 공식 제작용이 아니며, `render.py --all`에서도 제외된다. 기존 비교판을 재현할 때만 사용한다.

공식 제작은 [`examples/*.json`](../../)을 복제하고 `accent`와 `palette_preview`를 생략한다. 선택한 블루의 커버·차트 비교 샘플은 `blue-cover.json`, `blue-trend.json`이다. 상세 기록은 [이전 색상 비교](../../../docs/PALETTE_STUDIES.md)를 참고한다.
